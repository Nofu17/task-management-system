# ✅ Task Management System

A web-based task management application built with ASP.NET Core MVC and Entity Framework Core, allowing users to create, assign, and track tasks with status updates.

## ✨ Key Features

- 👤 User authentication and identity management
- 📋 Create, edit, and delete tasks
- 🏷️ Task status tracking (To Do, In Progress, Done)
- 🔗 User-to-task assignment

## 🛠️ Built With

- **ASP.NET Core MVC**
- **C#**
- **Entity Framework Core**
- **SQL Server**
